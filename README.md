# Einkaufen – Überarbeitete Version

Moderne Essensplaner-App mit KI-generierten Mahlzeitenplänen, Einkaufslisten und Angebotsübersicht.

## Features

- KI-generierte Essenspläne
- Einkaufslisten-Verwaltung
- Angebotsübersicht
- Gespeicherte Pläne
- Moderne, hochwertige UI im Disha-Style

## Tech Stack

- React + TypeScript
- Vite
- Bun

## Deployment

Über GitHub Pages oder Cloudflare Pages verbunden mit diesem Repository.
